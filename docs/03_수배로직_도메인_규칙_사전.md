# 수배로직 도메인 용어 및 문법 규칙 사전

본 문서는 수배로직 작성 및 검증 시 적용되는 핵심 도메인 용어, PID 체계, 로직 문법 규칙을 정리한 가이드입니다.

---

## 1. 도메인 핵심 용어 및 PID 체계

### 핵심 용어
- **영업사양 / 특성코드 / 특성값**: 엘리베이터 사양 명칭 / 코드(`EL_~` 또는 `CO_~`) / 코드가 가지는 선택 값
- **사양 그룹**: `EL_` 뒤 첫 알파벳 (A=기본, B=카내, C=승장, D=옵션, E=Layout, F=설계/교체, Z=정합성)
- **제어반 내부 자재 블록 (`A204A53`)**: 제어반 하위 자재 수배 로직 PID는 `EL_P...` 형태 대신 `A204A53_1` ~ `A204A53_97` 형태의 PID를 사용하며 TITLE 명칭을 확인 후 작성함.

### 일반 vs 선박용(Ship Elevator) PID 체계
| 구분 | 일반 엘리베이터 | 선박용 엘리베이터 (Ship Elevator) |
|---|---|---|
| Pick 로직 | `EL_P(Block No)` (예: `EL_PA103A`) | `SH_P(Block No)` (예: `SH_PB181B`) |
| 수량/주석 로직 | `(Block No)` (예: `A103A`) | `SH_(Block No)` (예: `SH_B181B`) |
| 자동 계산 로직 | `AUTO_EL_~` | `SH_AUTO_EL_~` |

## 2. PLM 로직 문법 규칙

1. **행(Row) 기반 조건 순차 평가**: 위에서 아래로, 좌에서 우로 평가하며 한 행은 하나의 규칙을 의미합니다.
2. **SPEC / CON (조건 쌍)**:
   - SPEC과 CON은 항상 쌍을 이룹니다. 한 행에 여러 쌍이 존재하면 AND 조건입니다.
   - CON 표기: 단일값(`KR00`), 목록(`,GTLX,GTSS,`), 와일드카드(`?GT?`), 비교식(`>1100`), 부정(`!N`, `!?KS?`)
3. **KEY / VAL (산출 쌍)**:
   - 결과 적용 대상(KEY)과 반영 값/자재코드(VAL)의 쌍입니다.
   - 주석 신규: `KEY=L_CMT`, `VAL=문구` / 주석 이어붙이기: `KEY=CMT`, `VAL={CMT}{L_CMT}`
   - 계산 로직 호출: `KEY=CALL`, `VAL=계산 PID명`
4. **ADDR / GOTO (분기 연산)**:
   - `GOTO=STOP`: 연산을 중단하고 완료합니다.
   - `GOTO={ADDR명}`: 해당 ADDR 라벨로 이동하여 연산을 계속합니다. (자기 자신 라벨 지정 시 무한루프 발생 주의)
