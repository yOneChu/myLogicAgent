## 5. 참고 사항 (수식 및 변수 정의)
* **수식 변수 [$ {K4} $] 계산식**:
  * `[$ 5*(round(((({EL_EAA_FRAME} - ({EL_ECCA} + 50)) * 0.5) + 12.5)/5,0)) $]`
* **참고 PID 수식 비교**:
  * `CAL_NEXBRAND_CMT` NO 99의 기존 K4 계산식 `[$ 5*(round(((({EL_EAA_FRAME} - ({EL_ECCA} + 50)) * 0.5) + 52.5)/5,0)) $]` 참고
  * 단, 본 요청에서는 `+52.5` 대신 **`+12.5`**를 적용함.
* **PLM 특성코드 매핑**:
  * `{AA_FRAME}` -> `EL_EAA_FRAME`
  * `{CA}` -> `EL_ECCA`
  * `{BG}` -> `EL_ECBG`

## 7. ⚠️ 추가 확인 및 결정이 필요한 정보 (Checklist)

실제 PLM 로직 반영 전 확정이 필요한 세부 정보 목록입니다.

1. **주석 입력 특성코드 정확한 특성명 확정**:
   * 조건 1에서 검사할 주석 입력 특성코드명이 `EL_ACMT`가 맞는지, 아니면 `EL_CMT`, `EL_L_CMT` 또는 별도의 특성명인지 최종 확인이 필요합니다.
2. **`K4` 변수의 산출 위치 확정**:
   * `[$ {K4} $]` 변수가 `BOM_E321A` 실행 이전에 `CAL_NEXBRAND_CMT` 등의 계산 로직 PID에서 미리 계산되어 전역 변수로 넘어오는지, 아니면 `BOM_E321A` 내부에서 직접 수식으로 산출해야 하는지 확인이 필요합니다.
3. **수식 조건(`EL_ECBG != EL_ECCA + 100`) 표현식 문법 타당성**:
   * PLM 조건식(`CON2`)에서 `![$ {EL_ECCA} + 100 $]` 형태로 직접 수식 비교가 가능한지, 또는 사전 계산 변수(예: `CHECK_BG`)를 만들어 비교할 것인지 확정해 주셔야 합니다.
