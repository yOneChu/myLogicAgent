### 💡 제안하는 업무 처리 프로세스 (개선안)

사용자님과 제가 오해 없이 정확하게 로직을 반영하기 위해 아래의 3단계로 진행하는 것을 추천해 드립니다.

1. **데이터 준비 요청 (DB 조회 승인)**
   - **사용자**: "BOM_E321A와 CAL_NEXBRAND_CMT 데이터 조회해서 준비해 줘."
   - **에이전트**: DB 쿼리 API를 통해 기존 로직을 조회 및 다운로드하고, 현재 구조(ADDR 흐름 등)를 파악하여 보고합니다.
2. **요청 내용 전달 (템플릿 사용)**
   - **사용자**: 아래 제공해 드리는 템플릿에 맞추어 변경 요건을 전달합니다.
3. **로직 반영 및 정합성 검증**
   - **에이전트**: 템플릿 내용을 분석하여 문법(SPEC/CON, KEY/VAL)에 맞게 로직을 생성하고, 변경된 결과물(CSV/Excel)과 검증 내역을 제공합니다.

### 📝 전산화 요청 템플릿 (복사해서 사용하세요)

향후 로직 추가나 변경을 요청하실 때 아래 양식을 복사하여 괄호 `[ ]` 안의 내용을 채워주시면, 제가 추측 없이 정확하게 처리할 수 있습니다.

```text
# 로직 전산화/변경 요청

1. 대상 PID
- 수정 대상 PID : [예: BOM_E321A]
- 참고용 PID : [예: CAL_NEXBRAND_CMT] (없으면 생략)

2. 변경 유형 및 위치
- 변경 유형 : [예: 신규 행 추가 / 기존 행 수정 / 삭제]
- 삽입 위치(ADDR) : [예: MAIN 분기 아래, 또는 기존 특정 조건 뒤. 모르면 '에이전트가 적절한 위치 제안'이라고 작성]

3. 적용 조건 (SPEC / CON)
- 조건 1 : [특성코드명] = [조건값]  (예: EL_ACMT = ,?V4612?,?V04612?,)
- 조건 2 : [특성코드명] = [조건값]  (예: EL_ECBG != EL_ECCA + 100)

4. 산출 결과 및 출력 내용 (KEY / VAL)
- KEY : [예: L_CMT (주석 신규) 또는 CMT (주석 이어붙이기) 등]
- VAL(출력 내용) : [예: "V0004612 적용 시 CEILING ASSY..."]

5. 참고 사항 (수식 및 변수 정의)
- [수식이 있다면 정확한 PLM 특성코드 기준으로 명시. 예: {AA_FRAME}은 EL_EAA_FRAME을 의미함 등]

6. 적용 사유
- [품질개선회의 안건 등 반영 배경 설명]
```

### 🔍 템플릿 작성 예시 (이전 요청사항 적용)

이전 질문하셨던 `BOM_E321A` 사례를 이 템플릿에 적용하면 아래와 같이 명확해집니다.

```text
# 로직 전산화/변경 요청

1. 대상 PID
- 수정 대상 PID : BOM_E321A
- 참고용 PID : CAL_NEXBRAND_CMT

2. 변경 유형 및 위치
- 변경 유형 : 정합성 체크를 위한 신규 행 추가
- 삽입 위치(ADDR) : 에이전트가 로직 흐름 파악 후 적절한 위치 제안 요망

3. 적용 조건 (SPEC / CON)
- 조건 1 : EL_ACMT(주석 특성코드 - 가칭) = ,?V4612?,?V04612?,?V004612?,?V0004612? 포함
- 조건 2 : 수식 판단 = EL_ECBG != (EL_ECCA + 100)

4. 산출 결과 및 출력 내용 (KEY / VAL)
- KEY : L_CMT
- VAL(출력 내용) : "V0004612 적용 시 CEILING ASSY(E321A) 및 ISOLATION BRKT(E321A16) 주석에 KE =[$ {K4} $], KF=[$ {K4} + 20 $]로 변경 적용돼었는지 확인할 것. (BG 비표준 값 반영)"

5. 참고 사항 (수식 및 변수 정의)
- [$ {K4} $] 계산식 : [$ 5*(round(((({EL_EAA_FRAME} - ({EL_ECCA} + 50)) * 0.5) + 12.5)/5,0)) $]
- 참고: CAL_NEXBRAND_CMT LINE 97 참고 하되, +52.5가 아니라 +12.5임. {AA_FRAME}은 EL_EAA_FRAME 임.

6. 적용 사유
- 품질개선회의 안건 (NEX-G CEILING ASSY ISOL. 브라켓 밀착 불량 개선 요청)
- 설계자가 V0004612 도면 적용 시 (BG-CA-100)/2를 KE에 적용하지 않는 것을 방지하기 위함
```

이렇게 명확한 특성코드(예: `EL_ACMT`, `EL_ECBG` 등)와 함께 요청해 주시면, 제가 DB에서 데이터를 즉시 가져와 로직 문법에 맞게 생성하고 결과를 만들어 드릴 수 있습니다! 프로세스나 템플릿에 더 추가하고 싶은 항목이 있으시면 언제든 말씀해 주세요.
